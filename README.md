# Página de Sites Favoritos 🌟

Este projeto é uma página web simples desenvolvida para praticar conceitos fundamentais de HTML e CSS, 
exibindo links e imagens de sites favoritos lado a lado de forma responsiva.

## 🚀 Tecnologias Utilizadas

- **HTML5**: Estruturação semântica da página.
- **CSS3**: Estilização e layout.

## 💻 Funcionalidades

- **Imagens Lado a Lado**: Utilização do CSS para alinhar os elementos horizontalmente.
- **Responsividade**: As imagens ajustam-se proporcionalmente ao tamanho da tela (`max-width: 100%`).
- **Compatibilidade**: Inclusão de meta tags para garantir a correta renderização em diferentes navegadores.
